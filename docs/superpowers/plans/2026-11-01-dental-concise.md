# Сокращение стоматологической анкеты

**Цель:** сократить чтение, прокрутку и повторные действия при сохранении всех 43 пунктов бумажного бланка и открытых ответов. Пользователь одобрил сокращение после предыдущего сравнения.

**Подход:** короткие названия состояний с сохранением сроков и пояснений, один заголовок вместо повторяющегося «Вы отметили», одна инструкция о множественном выборе на экран. Переключатель свободного ввода сокращён до «Текстом» и сохранён для даты, года, давления и длительности: на цифровой клавиатуре телефона без него неудобно набирать приблизительный ответ словами. Неопределённость — компактная кнопка «Не знаю» с доступной подписью. Поля, маршруты, валидация и печатные формулировки сохраняются.

PDF: один лист для заполненного профиля, два для длинного ответа; все 65 повторов контрольной фразы и названия аллергена/препарата сохранены.
