# Короткие страницы стоматологической анкеты

**Цель:** сохранить все 43 пункта, открытые ответы и исходную распечатку, сократив длину страниц на телефоне. Пользователь одобрил предложенное деление по темам. ФИО и дата рождения остаются у администратора; МИС нет. После проверки продолжается ранее разрешённое обновление сервера и создание тестовой ссылки.

**Архитектура:** маршрутом управляет backend. Новые приглашения получают `flow_version=2`, существующие без версии остаются на совместимом маршруте. Список здоровья делится на 6 страниц по 6–8 пунктов; состояние ответа и неопределённость обновляются только в пределах текущей страницы. Неотвеченные страницы не считаются отрицательными. Уточнения делятся на тематические страницы максимум по 3 группы; лекарства и аллергия показываются отдельно. Печатный бланк не меняется.

Здоровье: общее самочувствие; инфекции и перенесённые события; хронические заболевания; сердце и сосуды; нервная система и другие состояния; лечение, лекарства и привычки. Все значения покрываются ровно один раз, порядок печати прежний. Отправить анкету можно только после всех обязательных страниц. При исправлениях не теряются другие страницы, дата администратора и незавершённый ввод.

Дескриптор `dental` получает `progress: {current,total,label}`, `navigation: [{step_key,label}]`, `page?: {kind,current,total}`. `editable_steps` сохраняется; переходы назад проверяет сервер. Frontend показывает правдивый прогресс, одну кнопку «Назад» и компактный выбор более раннего ответа. Текстовые быстрые ответы сохраняют действующую логику подстановки/скрытия/восстановления.

- [x] Backend: регрессии границ страницы, неизвестных значений, исправления и запрета пропуска страниц; реализация версии маршрута и метаданных.
- [x] Frontend: прогресс из дескриптора, ответы только текущего списка, независимые черновики, компактный возврат и проверки.
- [x] Интеграция: старые и новые анкеты, здоровый/сложный/неопределённый профиль, перезагрузка и исправление; сравнение итоговых печатных данных.
- [x] Мобильные проверки 320/390 px, TypeScript/ESLint и профильные тесты. Время людей не подменять временем робота.
- [ ] Резервная копия и выпуск на существующий сервер; отдельная новая незаполненная ссылка пользователю.

Проверено до выпуска: backend 156 passed, frontend 553 passed, TypeScript и ESLint прошли. Семь браузерных сценариев завершились; короткие страницы здоровья 903–1049 CSS px при ширине 390, горизонтальной прокрутки на 320/390 нет. Восстановление проверяется после готовности поля к вводу, а не только сетевого ожидания. У native select исправлено доступное имя для возврата.
