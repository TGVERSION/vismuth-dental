# Исходная анкета врача; первичный приём по умолчанию — 07.11.2026

Рабочий сайт: https://anketa.vismuth.ru. Репозиторий [TGVERSION/vismuth-dental](https://github.com/TGVERSION/vismuth-dental), основная ветка `dental-questionnaire`.

Два последовательных выпуска: `original-chat-20261107T122406Z` (исходный чат/оформление/контраст) и `primary-only-20261107T123155Z` (первичный приём автоматически). Последняя проверка серверов — 17:34 Екатеринбург. Схема базы остаётся `0019_staff_roles`, миграций нет. Права, пользователи, настройки клиник и заявок не откатывались.

## Что исправлено

Предыдущее исправление показывало структурированную гастроанкету как переписку, сохраняя длинные списки вариантов. По уточнению пользователя восстановлен именно исходный сценарий: «Что вас беспокоит?» со свободным ответом, затем прежний чат с уточнениями и контекстными быстрыми ответами. Автоматический вход новых анкет в расширенный `gastro` отключён. Сохранённые расширенные анкеты совместимы; пациент может продолжить такую сессию либо явно начать обычный опрос, сохранив прежнюю на сервере отдельно.

Восстановлены исходные компоненты публичной обычной анкеты из `32d85c9`: выбор врача, чат/ввод/прогресс, данные пациента/приёма, шторки и код; исходная публичная палитра. Обновлённая административная часть и роли остаются прежними.

Причина нечитаемости была воспроизведена: клиника использует почти белый `#F3F8FD`; раньше этим цветом рисовались специальности и контуры/текст быстрых ответов на белом фоне. Заливка бренда сохранена, для текста и контуров введён отдельный читаемый `--q-accent`, выбираемый по контрасту APCA. Два теста фиксируют светлый бренд и сохранение тёмного акцента. Изменения цвета самой клиники в БД не выполнялись.

По дополнительному решению пользователя пациент не выбирает первичный/повторный приём. Новая анкета сразу получает `visit_type=primary`. После врача (или его специальности) начинается `complaint`. Ранее открытый выбор при возобновлении также безопасно переводится в первичный чат; состояние повторно проверяется под блокировкой, чтобы не сбросить конкурентно принятый ответ. Уже начатые повторные ответы не переклассифицируются массово. Демонстрационная заглушка синхронизирована; legacy-тесты повторных сессий сохранены отдельно.
