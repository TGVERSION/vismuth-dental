## Причина и исправление

Первичный взрослый приём гастроэнтеролога переходил в `gastro_form`, который рендерился как экран с несколькими вопросами и кнопками действий. Изменение оформления не возвращало привычный чат. Исправлен именно рендер: один вопрос за раз, ответы в переписке, компактный ввод, быстрый единичный выбор и подтверждение множественного. Серверная машина состояний, вопросы, медицинские предупреждения, лимиты и сохранённые ответы остаются прежними. Уже начатая гастроанкета может продолжаться с текущего серверного раздела.

Клиент последовательно собирает поля раздела и отправляет прежний контракт с `step_key`, `revision`, `selections`, `texts`. При возврате к ответу заново проверяет условные поля; скрытый текст не отправляет. История чата сохраняется между серверными разделами в текущей сессии, без дополнительного хранения медицинского текста в браузере. Ошибка отправки сохраняет текст в поле. Восстановление после перезагрузки опирается на сохранённый серверный раздел.

- TypeScript и ESLint без ошибок; 587 frontend-тестов. Два новых теста покрывают зависимые переходы, подписи вариантов и сохранение длинного текста.
- Локальный браузер: обязательный ответ, условные поля, возврат и изменение ответа, исключение скрытого текста, длинный ответ 6000 символов без обрезки, ошибка и повтор отправки, история между разделами, экраны 375 и 1440 px.
- Дополнительно полный браузерный проход с настоящей чистой серверной машиной состояний: жалобы → боль → важные признаки → лекарства → аллергии → здоровье → семья → обследования → история → имя/дата → проверка → вопросы врачу → код.
