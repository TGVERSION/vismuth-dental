# Стоматологическая анкета в формате переписки

**Цель:** использовать оформление чата общей анкеты, сохранив текущие быстрые ответы, группировку и число отправок.

**Решение:** история — пары вопрос/принятый ответ, построенные backend по сохранённым данным. На клиенте общие пузыри `ChatBubble`, закреплённая шапка и кнопка отправки; текущий вопрос и варианты находятся в прокручиваемой ленте. Прошлые сообщения доступны только для чтения. ФИО/дата рождения остаются у администратора; печатный бланк и алгоритм переходов не меняются. Никаких искусственных задержек «печатает» и дополнительных подтверждений.

**Архитектура:** `dental/history.py` строит аддитивное поле `dental.history` из разрешённых пройденных шагов. Незавершённые страницы не считаются ответом «Нет», пустые необязательные поля — «Не указано». Закрытые уточнения ИИ добавляются отдельно; текущий вопрос не дублируется. История не сохраняется повторно в браузере или БД. `DentalShell` отображает её и активный ответ с поддержкой Visual Viewport. При переходе виден старт нового вопроса, при появлении клавиатуры — активное поле.
