## Согласованный результат

Только первичные взрослые гастропациенты по ссылкам врача/клиники. Без возраста, даты рождения и времени приёма. Имя, необязательное отчество, дата, код сохраняются. Короткий семейный анамнез для всех; условные вопросы по жалобам; необязательная длинная история свободным текстом либо по разделам. Сначала все уточнения и проверка, последним — собственный список вопросов пациента врачу, затем только отправка и код. Карточка врача хранит исходные ответы, неизвестность, историю и отдельный список вопросов. Действующая стоматология и остальные специальности сохраняют поведение.

## Архитектура

Отдельные чистые `backend/app/services/gastro/{questions,flow,summary}.py`, тонкий DB-сервис, JSONB `gastro_answers` и миграция. Существующие публичные endpoints и токен сессии, сервер управляет переходами. `StepDescriptor.gastro` описывает поля/значения/сводку/ревизию; frontend рендерит их через отдельный компонент. Все временные и текущие факты привязаны к жалобе; пропуск не становится отрицанием. Модель необязательна; запрос в фоне, опоздавший ответ не отменяет решение закончить уточнения.

- [x] Необязательный ML: отдельный гастропромпт, 0–2 вопроса, отказ от возраста/советов/диагнозов, фон без блокировки отправки, терминальный пропуск и защита от позднего результата. Тесты используют заглушку модели, без отправки медицинских данных.
