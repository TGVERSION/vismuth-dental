# Быстрые ответы, данные администратора и выпуск

Пользователь уточнил: ФИО и дату рождения вводит администратор стоматологии, интеграции с МИС нет и не будет. После исправления разрешены обновление существующего сервера и создание персональной тестовой ссылки.

Текстовые подсказки заполняют редактируемое поле и скрываются при непустом ответе; это относится и к «Не помню». После очистки поля подсказки доступны снова. Кнопки множественного выбора остаются переключателями. «Дозу не помню» становится текстовой подсказкой; старые выбранные значения дозы сохраняются при редактировании. Нажатие подсказки не отправляет шаг.

Дата рождения убирается из публичных вопросов. Администратор может задать её при создании ссылки; значение хранится в существующем JSON ответов, сохраняется при отправке пациентом остальных полей и попадает в прежнюю печатную шапку. Поле необязательное для совместимости существующих клиентов. Без введённой администратором даты печатное поле остаётся пустым, пациенту оно не предъявляется. Новые публичные запросы не могут перезаписать дату.

- [ ] Регрессии переноса даты администратора в печать и запрета её изменения пациентом; совместимость старого выбора неизвестной дозы.
- [ ] Реализация backend/frontend и обновление контрактов.
- [ ] Тесты frontend/backend, TypeScript, ESLint, мобильный браузер: подсказки скрываются и восстанавливаются, нет вопросов о ФИО/дате, черновики и печать сохранены.
- [ ] Сверка сервера, резервная копия, обновление только затронутых исходников и контейнеров. Подтверждение работоспособности после выпуска.
- [ ] Создание вымышленного пациента и отдельной незаполненной ссылки для пользователя. Не расходовать её при автоматическом прохождении.
