# Синтетическая проверка гастроанкеты

`gastro_fixture.py` запускает локальный FastAPI-стенд на `127.0.0.1:8017`.
Он использует настоящие чистые `gastro.flow`/`gastro.summary`, но хранит только
синтетические сессии в памяти и выдаёт тестовые коды. Это проверка UI и сценария,
не замена проверки публичного DB-роутера, PostgreSQL и миграций.

Нужны зависимости backend и frontend, Node.js и Playwright с браузером.
На Windows по умолчанию используется установленный Edge; другой канал можно
указать в `PLAYWRIGHT_CHANNEL`. Если Playwright установлен вне проекта,
`PLAYWRIGHT_MODULE` задаёт путь к его модулю. Скрипт не устанавливает пакеты.

В первом терминале из корня репозитория:

```powershell
python scripts/qa/gastro_fixture.py
```

Во втором терминале из `frontend`:

```powershell
$env:MOCKS='speech'
$env:API_MAIN_URL='http://127.0.0.1:8017'
npm run dev -- --webpack --hostname 127.0.0.1 -p 3017
```

После готовности frontend в третьем терминале из корня:

```powershell
node scripts/qa/gastro_browser.cjs
```

Проверяются простой пациент и история на 13 140 символов: полное сохранение
текста, отсутствие полей возраста/времени, последний список вопросов и его
восстановление после «Назад», порядок вопросов и их отделение от жалоб,
получение кода, отсутствие горизонтального переполнения на телефоне.

Результаты и скриншоты сохраняются в `scripts/qa/output/`, исключённом из Git.
Не используйте этот стенд с настоящими пациентскими данными и не публикуйте
его как backend приложения. Все процессы завершаются обычным Ctrl+C.
