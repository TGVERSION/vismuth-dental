# Направления клиники и навигация

## Требования

1. Пункт меню «Протоколы» виден только пользователю с глобальной ролью `super_admin`. Это изменение видимости вкладки, а не запрет API протоколов или создания протокола из анкеты.
2. `/registry` называется «Анкеты для стоматологии» в меню, заголовке страницы и относящихся к разделу подсказках.
3. `/questionnaires` называется «Анкеты для врачей» в меню и заголовке страницы.
4. Одна клиника может одновременно использовать стоматологические и обычные врачебные анкеты.

## Предлагаемое поведение

В настройке направления клиники доступны три варианта:

- Многопрофильная — обычные анкеты по ссылке/QR врача или клиники.
- Стоматология — стоматологические анкеты по персональным ссылкам регистратуры.
- Многопрофильная и стоматология — одновременно оба сценария.

В комбинированном режиме общая ссылка и ссылки врачей запускают существующий обычный сценарий (включая гастроэнтерологический по текущим правилам). Регистратура создаёт отдельные стоматологические приглашения. Пациенту не добавляется выбор между двумя видами анкет.

Раздел стоматологии остаётся доступен администратору клиники при включённом стоматологическом направлении. Раздел врачебных анкет сохраняет существующие права: завершённые стоматологические анкеты доступны врачам клиники, остальные — по текущему правилу принадлежности врачу.

Существующие клиники сохраняют настройки, ссылки и данные. Новое направление включается явно в настройках супер-администратора. Начатые анкеты продолжают работать по сохранённому виду анкеты.

## Варианты реализации

Рекомендуется расширить существующий `questionnaire_kind` значением `mixed`: это три явных состояния, без переноса данных и изменения формата действующих запросов. Вместимость существующей колонки достаточна; при реализации нужно проверить ограничения базы.

Альтернатива — два независимых флага направлений. Они удобны при дальнейшем расширении списка направлений, но сейчас потребуют миграции, поддержки старого поля и дополнительной проверки состояния «ничего не выбрано».

## Область изменений

- Навигация: подписи и видимость протоколов по текущей роли, без краткого показа вкладки при загрузке пользователя.
- Настройки: новый вариант направления и понятная подсказка о двух способах выдачи ссылок.
- Backend: схемы клиник, создание приглашений, разрешение общих ссылок и запуска обычной анкеты в комбинированном режиме.
- Frontend: типы API, настройка клиники и доступность раздела стоматологии.
- Документация: контракты клиник, публичных анкет и стоматологических приглашений; описание видимости вкладки протоколов.

## Проверка

- Навигация для супер-администратора и остальных ролей, включая ещё не загруженного пользователя.
- Создание и редактирование клиники во всех трёх режимах.
- В комбинированной клинике работают и обычная публичная ссылка, и стоматологическое приглашение.
- Чисто стоматологическая клиника по-прежнему блокирует обычные публичные анкеты; многопрофильная не создаёт стоматологические приглашения.
- Смена направления не меняет вид уже начатой анкеты.
- Существующие проверки стоматологии и гастроанкеты, проверка типов и сборка frontend.
